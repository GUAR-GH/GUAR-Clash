# Support

Include the exact application version, operating system and architecture, installer
format, separately installed engine/version, steps to reproduce, expected result,
and actual result. State whether the problem occurs in a historical GPL version
or an independent preview. Features and support differ by release.

Use the public issue tracker for ordinary bugs and feature requests. Public issues
are visible to everyone. Remove credentials, subscription URLs, authentication
headers, IP/connection history and private configurations before sharing logs or
screenshots. A redacted minimal reproduction is usually more useful than a full
configuration.

The independent preview does not install or bundle a VPN engine. Engine downloads,
engine licensing and engine-side behavior are handled by that engine's project.
Describe controller/protocol compatibility issues here without sharing the engine
controller secret. No response-time or platform-support commitment is made by this
transition scaffold.
